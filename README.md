# Samuels Musical Adventure

Samuels Musical Adventure is a small game about music that I like. It shows a few of my favourite artists and displays them in different styles of rooms. It was a fun game to make as I was able to practice using Godot and create some scenes in apps I'm familiar with like Figma!

## How To Play:

1. Go to the demo link.

2. Press play!

## Inspiration:

Music! I've always just enjoyed music, and when given the opportunity to create something with Hack Club, I knew it would be about Music. Although this is a short game, it will help me in the future with becoming more experienced in tools like Figma and Godot. It was also designed in a cool 8-Bit theme using inspirations from older games in a style that ive enjoyed.

I used tools to create the music into 8-Bit sounding audio to match the theme idea.
